# Grupo 3 — Base de datos

## Proyecto: Servidor de bases de datos con MariaDB

Configuración de un servidor MariaDB en una máquina virtual Alpine Linux usando Docker. El proyecto documentará la creación de la base de datos, usuarios, tablas y registros, además de las pruebas de conexión y persistencia.

## Objetivos

- Desplegar MariaDB con Docker en Alpine Linux.
- Crear una base de datos y un usuario para el equipo.
- Crear tablas e insertar registros de ejemplo.
- Comprobar el acceso desde la interfaz web de administración y desde otros equipos.
- Verificar que los datos persisten al reiniciar o recrear el contenedor usando un volumen.

## Evidencias

Se agregarán capturas de la tabla con los registros iniciales, de las inserciones realizadas desde otros equipos y de la consulta final desde la terminal de la VM.
